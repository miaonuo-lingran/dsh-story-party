      AI 每次读多少历史？

      • 最近 30 条：默认，便宜、够日常；长局会忘掉早期细节。
      • 最近 100 条：记得更久，token 大约 3 倍。
      • 全部历史：每轮把整段对话重新发送，长局会非常贵；适合短篇、调试或精读。

      这里只决定「发给模型多少条」。房间消息永远全部保存在房主本机，不受影响；改动只对**新建**的房间生效。

      开房前，先确认朋友怎么进来

      房间只跑在你这台机器上，能不能连上取决于网络。

      • 同一个 Wi-Fi / 手机热点：直接用「复制邀请链接」里的「局域网」地址。
      • 不在同一网络：组虚拟局域网（蒲公英 / ZeroTier / Tailscale），用虚拟 IP 走 http 访问。
      • 想公网直接开：cpolar / cloudflared 这类 https 穿透，把域名填进「公网地址」。
      • 樱花：TCP 隧道会被拦成 501（HTTP 明文），HTTP 隧道需要先备案，不建议临时联机用。
